# Iris Clustering Project Using KMeans and Hierarchical Methods

## Introduction

This project focuses on applying unsupervised machine learning techniques to the Iris dataset. The goal is to identify natural groupings in the data without using predefined labels. Clustering helps in understanding hidden patterns and relationships between data points based on their features.

## Dataset

The dataset used is the Iris dataset, which contains measurements of sepal length, sepal width, petal length, and petal width for different flower samples. The species column is removed since clustering does not use target labels.

## Objective

The objective of this project is to apply KMeans and Hierarchical clustering algorithms to group similar data points and visualize the structure of the dataset.

## Methods Used:

* KMeans Clustering
* Hierarchical Clustering
* Feature Scaling
* Elbow Method
* Dendrogram Visualization

## Results

KMeans clustering grouped the data into distinct clusters based on feature similarity. Hierarchical clustering also formed clusters, and the dendrogram helped visualize the grouping structure and relationships between data points.

## Conclusion

This project demonstrates how clustering techniques can be used to discover patterns in data without prior labels. Both KMeans and Hierarchical clustering successfully identified meaningful groupings in the Iris dataset, showing the effectiveness of unsupervised learning methods for structured data.
